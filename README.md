# Arduino FeederBot

FeederBot is an Arduino-based prototype developed as part of an
introductory engineering design course. The larger class project
focused on designing automated systems to assist backyard chicken
farmers with routine tasks.

## Project Overview

FeederBot was designed as an automated feeding system for a backyard
chicken coop. The concept uses a rail-based system to move between
feeding locations and dispense feed.

The prototype combines Arduino programming, circuit design, sensors,
motor control, and CAD modeling to demonstrate how the system could
operate.

## Prototype Components

The prototype uses components including:

- Arduino Uno
- HC-SR04 ultrasonic distance sensor
- Servo motor
- Push button
- LED
- Buzzer
- Breadboard
- Resistors
- Supporting electronic components

## How It Works

The Arduino controls the prototype and coordinates its electronic
components.

The ultrasonic sensor provides distance measurements that can be used
for obstacle detection. A servo motor represents the mechanical
feeding mechanism, while additional components provide user input and
system feedback.

The overall FeederBot concept was designed to travel along a rail,
stop at designated feeding locations, dispense feed, and continue
through its feeding cycle.
